Вам даны дизайн макеты маркетплейса драгоценных камней. Нужно спроектировать всю систему на их основе и реализовать её.

Что должно быть выполнено в самом начале:

Верхнеуровневая архитектура системы
ER-диаграммы структуры БД
Поэтапный план разработки состоящий из крупных блоков
Декомпозиция крупных блоков на конкретные задачи для исполнения
Далее в зависимости от времени можно выбирать конкретные этапы и выполнять их поочередно, примерный список того что нужно сделать:
Сервис пользователей с аутентификацией, 2FA по смс-кодам или one-time-кодам (Google Authenticator) и авторизацией (ролевая модель пользователь, модератор, администратор)
Сервис с чатом поддержки (с возможностью переключения между живым оператором и AI-ассистентом)
Сервис драгоценных камней с основной бизнес логикой
Сервис AI-консультанта (RAG-архитектура): Отдельный микросервис, который асинхронно векторизует базу знаний (характеристики камней, геммологические сертификаты, правила ухода) и сохраняет их в векторную базу данных (например, Qdrant или ChromaDB). Сервис должен анализировать сложные запросы пользователей в чате (например, «Какой камень с твердостью выше 8 по Моосу подойдет для повседневного кольца в бюджете до $2000?»), искать релевантные камни и статьи, а затем формировать контекст для LLM, чтобы выдать точный и экспертный ответ. …
CI/CD для деплоя проекта и его конечный деплой на выделенный сервер
